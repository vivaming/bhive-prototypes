# BIHIVE ChartSpec v1 (local prototype)

The chart module in `chart-spec.js` validates a JSON ChartSpec and provides canonical serialization, an explicit data release gate, a poll-gap transform, and versioned dark/light theme tokens. The page reads its fixture through the generated classic script `specs/legacy-curia-fixture.js`, so the experience works from a static file preview without a JSON fetch. The JSON file remains canonical; `pnpm charts:sync` regenerates the runtime script and `pnpm charts:qa` verifies that they match byte for byte.

`legacy-curia-fixture.json` preserves the poll snapshot and line-series values that were already present in the prototype. It is deliberately marked `UNVERIFIED_LEGACY_FIXTURE` with `releaseGate: HOLD`: no source snapshot, fieldwork dates, methodology, or per-wave mapping is available in the repository. The title/labels and values are therefore useful only for exercising the existing visualization. The chart must not be represented as source-verified or release-ready until a provenance record is added and independently checked.

The line renderer and the party-vote snapshot read from the same ChartSpec. `datasetHash` is SHA-256 over `BIHIVE_CHARTS.canonicalData(spec)`, which canonicalizes the display period, snapshot view, dataset, and scale policy. The QA suite checks that hash, the snapshot IDs, latest values, zero-baseline bar policy, transform output, preservation of the legacy values, and that an explicit release `HOLD` cannot be overridden by verified provenance.

`render-spec.mjs` provides deterministic SVG output for comparison bars, diverging bars, lines, slopes, dot plots, contribution waterfalls, and scatter plots. `pnpm charts:gallery-qa` renders 13 explicitly synthetic development specimens in dark and light themes and exports SVG and PNG files under `work/chart-gallery/`. Its 47 scenarios cover domains, zero baselines, compact cards, missing values, label wrapping, XML escaping, theme bounds, and release-gate behavior. The gallery catalog and renderer are excluded from the production build; they do not add invented examples to the site.

Run `pnpm charts:qa` for the locked poll-fixture checks, `pnpm charts:gallery-qa` for visual-template fixtures, and `pnpm qa:all` for the complete local pipeline. The gallery proves rendering and layout behavior only. Its data is synthetic and every specimen stays on `HOLD`; it is not a set of source-approved published charts or a live XPI workflow.
